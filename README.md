📍Взаємодія з програмою
 Для початку роботи необхідно зареєструватися або авторизуватися.
Можна додати оголошення про продаж автомобіля.
 Після того як ми натиснемо кнопку "Додати оголошення" ми потрапимо на форму, де зможемо:

▪️ створити докладний опис

▪️ завантажити фото

▪️ призначити ціну

▪️ вказати рік випуску

▪️ вказати пробіг

▪️ вибрати зі списків основні технічні параметри автомобіля


Тільки користувач, який створив оголошення, має можливість зняти свій автомобіль з продажу, змінивши статус з "Актуально" на "Продано"

На сайті передбачений фільтр, який дозволяє вибрати авто:

▪️ Все

▪️ У продажу

▪️ Продані

▪️ Нові оголошення


📍Запуск проєкту

Запустіть SQL Shell (psql) з пакету PostgreSQL. Створіть базу даних проєкту "cars\_sale\_db", виконавши команду `create database cars\_sale\_db`;

Запустіть ваш термінал (наприклад, для Windows це програма cmd), перейдіть у папку з вашим проєктом та запустіть проєкт командою `mvn spring-boot:run`.

Після запуску, для початку роботи з "Платформою для продажу автомобілів" - відкрийте браузер і перейдіть за посиланням [http://localhost:8080/index](http://localhost:8080/index).
