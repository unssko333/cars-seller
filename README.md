На першій сторінці представлені всі оголошення у форматі таблиці. Є можливість фільтрації оголошень за заздалегідь визначеними параметрами. Можна зайти в конкретне оголошення та переглянути детальну інформацію про автомобіль, що продається. Для додавання оголошень необхідно зареєструватися на сайті. Для перегляду оголошень реєстрація не потрібна.

Технологічний стек

У проєкті використовуються:

\- Java 17

\- Spring Boot 2.7

\- Hibernate 5.6

\- PostgreSQL 14

\- H2 Database 2.1

\- Liquibase 4.18

\- Thymeleaf 3

\- Bootstrap 5

\- Maven 3.8

\- JUnit 5

\- AssertJ 3.23

Вимоги до середовища

Для запуску проєкту вам необхідно встановити:

\- Java 17

\- PostgreSQL 14

\- Maven 3.8

Запуск проєкту

Запустіть SQL Shell (psql) з пакету PostgreSQL. Створіть базу даних проєкту "cars\_sale\_db", виконавши команду `create database cars\_sale\_db`;

Запустіть ваш термінал (наприклад, для Windows це програма cmd), перейдіть у папку з вашим проєктом та запустіть проєкт командою `mvn spring-boot:run`.

Після запуску, для початку роботи з "Платформою для продажу автомобілів" - відкрийте браузер і перейдіть за посиланням [http://localhost:8080/index](http://localhost:8080/index).
